# Buhari Residence - 3D & 360° Architectural Model

An interactive, web-based 3D architectural visualization of the **Buhari Residence**. Built with Three.js, HTML5, CSS3, and JavaScript.

## Features

- **Interactive 3D Orbit Navigation**: Smooth mouse and touch rotation, zooming, and panning across exterior and interior views.
- **Room & Floor Navigation**: Quick camera presets for exploring individual rooms, living spaces, and exterior vantage points.
- **Interactive Hotspots & Toggles**: Visual indicators, markers, and toggles for elements and annotations.
- **Lighting & Atmospheric Controls**: Dynamic day/night and ambient lighting presets.
- **Zero-Dependency Setup**: Runs directly in the browser without complex build steps.

## Getting Started

### Option 1: Direct File
Simply double-click [`index.html`](index.html) or [`Buhari Residence - 3D Model.html`](Buhari%20Residence%20-%203D%20Model.html) in your browser (Google Chrome, Firefox, Safari, Microsoft Edge).

### Option 2: Local HTTP Server (Recommended)
Using Python:
```bash
python -m http.server 8000
```
Or using Node.js:
```bash
npx serve
```
Then navigate to `http://localhost:8000` in your web browser.
